# 内容可信度规范

这个项目的目标不是把页面堆满，而是让学习者知道哪些内容可以当作概念基础，哪些只是教学演示，哪些还需要复核。

## 可信度等级

| 等级 | 名称 | 页面说明 |
|---|---|---|
| A | 已校对 | 公式、定义、历史脉络已对照公开来源检查。 |
| B | 教学简化 | 核心方向可信，但图像、数据或训练过程为简化演示。 |
| C | 待复核 | 旧脚本迁移或自动整理内容，还没有系统校对。 |

默认情况下，旧章节先按 **B/C** 处理。只有完成来源尾注和人工校对后，才可以标成 **A**。

## 写作规则

- 强结论要有边界：写“在这个教学设置中”“通常先尝试”“需要结合验证集判断”。
- 工程经验要避免绝对化：少写“90% 情况”“工业界都这样”，除非有明确来源或统计依据。
- 历史内容要能追到论文或公开资料。
- 模拟图必须说明它简化了什么。
- 热力图、Grad-CAM、注意力权重等解释性图，只能称为“线索”或“证据之一”，不能称为完整因果解释。

## 质量门后续要补的检查

- 扫描高风险词：`一定`、`绝对`、`90%`、`工业界`、`最经典`、`致命`。
- 如果章节出现高风险词，需要同页有“边界说明”或“来源尾注”。
- 新增章节必须至少声明一个可信度等级。
- 核心章节的来源尾注必须指向 `docs/references/source_catalog.md` 中的编号或公开链接。
